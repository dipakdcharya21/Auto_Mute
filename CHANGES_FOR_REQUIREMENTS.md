# ICT107 requirement updates

- Exactly three selectable languages: English, Nepali, and Hindi.
- Local sign-in accepts any valid email address and password of at least four characters.
- Passwords are never saved and no network authentication is used.
- Notifications are scheduled before meetings, when meetings start, and when meetings end.
- Notification text follows the selected language.
- Login visuals and card styling were polished for mobile, web, and desktop layouts.

## Platform note
Android can change the actual system silent/vibration state after permission is granted. Other platforms keep schedules, UI status, and supported notifications, but operating systems such as iOS and Web do not permit third-party apps to change the global ringer state.
